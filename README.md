## 🚀 Featured Builds

**⚡ Distributed Rate Limiter & Load Balancer**

Built a backend system that handles high-throughput traffic without cracking — consistent hashing to distribute load evenly, token bucket for rate limiting, and distributed state management across nodes. The interesting challenge: keeping everything consistent when the system is inherently concurrent.

`Python` · `AWS` · `SQL` &nbsp;|&nbsp; `consistent hashing` · `token bucket` · `distributed state` · `load balancing`

<br/>

**🤖 FieldMind**

AI inspection platform designed for environments where the internet isn't guaranteed. The model runs on-device via TFLite, data syncs peer-to-peer using CRDTs to avoid conflicts, and active learning lets the system improve from field data without needing a server. Built for the real world, not ideal conditions.

`Python` · `TensorFlow Lite` · `Edge AI` &nbsp;|&nbsp; `on-device inference` · `P2P sync` · `CRDTs` · `active learning`

<br/>

**💉 VVM Vision**

Vaccine supply-chain intelligence that combines computer vision with routing logic. Reads VVM (Vaccine Vial Monitor) images to assess heat exposure, tracks GPS checkpoints, and makes routing decisions that keep vaccines effective end-to-end. Technical problem with a real-world stake.

`Python` · `Computer Vision` · `Optimization` &nbsp;|&nbsp; `VVM detection` · `heat-aware routing` · `GPS checkpoints` · `batch traceability`

<br/>

**🛡️ AI Financial Guardian**

Agentic workflow that sits between you and a payment and asks: *should this actually happen this way?* Detects subscription traps, compares plans, checks payment readiness, and flags decisions worth reconsidering — before the money moves.

`Agentic AI` · `Browser Automation` · `LLMs` &nbsp;|&nbsp; `subscription intelligence` · `payment readiness` · `plan comparison`
